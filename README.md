# TokoKita – ECommerce

## Deskripsi
TokoKita merupakan aplikasi marketplace berbasis web yang dibuat untuk memenuhi tugas mata kuliah Pemrograman Web. 
Aplikasi ini memungkinkan pengguna untuk melihat produk, menambahkan produk ke keranjang, melakukan checkout,
dan melihat riwayat pesanan.

## Fitur Aplikasi

### Admin
- Login Admin
- Dashboard Admin
- Tambah, tampil, edit, dan hapus produk
- Mengelola pesanan pengguna
- Mengubah status pesanan
- Melihat dan mengelola data pengguna

### User
- Registrasi dan Login
- Melihat katalog produk
- Melihat detail produk
- Menambahkan produk ke keranjang
- Menghapus produk dari keranjang
- Melakukan checkout
- Melihat riwayat pesanan

## Teknologi yang Digunakan
- PHP Native
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Instalasi dan Menjalankan Project

1. Install dan jalankan XAMPP.
2. Aktifkan Apache dan MySQL.
3. Salin folder project ke dalam `htdocs`.
4. Buka phpMyAdmin.
5. Buat database dengan nama `db_tokokita`.
6. Import file database TokoKita.
7. Buka browser.
8. Akses alamat berikut:

   `http://localhost/Github/TR_PW_TokoKita/`

## Database
Nama database: `db_tokokita`

Database digunakan untuk menyimpan data pengguna, kategori, produk, keranjang, pesanan, dan detail pesanan.
